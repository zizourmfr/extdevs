# ExtDevs landing page

A static first version of the ExtDevs coming-soon site.

## Run locally
Open `index.html` in a browser, or use any static server:

    python3 -m http.server 8000

Then visit http://localhost:8000

## Deploy
Upload `index.html`, `styles.css`, and `script.js` to your web host.
For production, replace the demo signup form handler with your email provider/API.

## Notes
- No framework or build step required.
- Responsive layout.
- Dark developer/AI infrastructure aesthetic.
- Signup interaction is currently front-end only.
